# ai-readiness-check

Check how ready a website is for AI crawlers, AI search, and AI agents: robots.txt rules, llms.txt, schema.org JSON-LD, Markdown versions of pages, sitemaps, MCP discovery, and more. Run it on your own machine, in CI, or from an AI coding agent.

Each failing check links to a prompt in [awesome-ai-website-files](https://github.com/tristandenyer/awesome-ai-website-files) that explains how to fix it.

**Status:** in development. Until the first release, use the web version at [tristandenyer.com/ai-readiness-check](https://www.tristandenyer.com/ai-readiness-check).
